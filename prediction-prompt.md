# Locked Changed-Input Record

## Before the run

Close AI and keep the changed scenario unrun. Use the original app settings as the reference case. Choose one previously untested value for either the incremental annual cost or the minimum SGOV reserve. Keep the other control at its default and leave the dataset, window, return floor and model fixed. Choose a value you can enter in the app.

In your own words, answer these questions.

1. **What exactly will I change?** Name the control, the original value, the new value and the units.
2. **What do I expect to see?** Predict the direction and approximate size of a change in at least one observable result, such as a fund weight or estimated net return. State whether you expect the optimizer to find a feasible portfolio. If you expect it to stop, identify the rule you think will prevent feasibility.
3. **What would that mean for my decision?** Say whether the predicted result would change your recommendation and why. Name an observation that would make you reconsider.
4. **How will I test it?** Name the app tab and control you’ll use, where you’ll read the result and what you’ll compare it with.

Put your answers in the Locked Changed-Input Record in `docs/validation-and-ai-use.md`. Commit and push your prediction to GitHub before you run the changed setting. Save the prediction commit URL.

## After the run

Use the exact setting you committed. Save the observed weights, estimated net return and verdict, or the stop message if the search finds no feasible allocation. Add the prediction commit URL, the result evidence, how the observation compared with your prediction and its actual effect on your decision. Keep the original prediction visible in the pre-run commit.
